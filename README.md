DAY 11 — LAB 11
Canva Magic Studio: Aviation Mini-Campaign and Brand Consistency
Programme: BBA Aviation Management
Course: Generative AI for Business
Tools: Canva, Canva Magic Studio, ChatGPT or Google Gemini, and GitHub
Technical Requirement: No coding required
Objective
To use Canva’s AI-assisted design features to create a consistent aviation mini-campaign and evaluate the outputs for accuracy, branding, professionalism and responsible use.
Learning Outcomes
After completing this lab, students will be able to:
Create aviation-related designs using Canva.
Generate visual content using Magic Media.
Extend an image using Magic Expand, where available.
modify selected image elements using Magic Edit, where available.
Apply a consistent colour palette and typography.
Use a brand kit or manually created brand guide.
Adapt one design for multiple platforms.
Check AI-generated visuals for inaccurate text and imagery.
Evaluate a campaign using a brand-and-accuracy checklist.
Upload the completed campaign to GitHub.
Important Note
The availability and names of Canva AI features may vary according to the account type, institutional access and current Canva interface.
If a feature is unavailable, students may use a comparable Canva editing feature and record the alternative used.
Step 1 — Understand the Mini-Campaign
A mini-campaign is a small collection of related communication materials created for one objective and audience.
For this activity, students will create:
One square social-media post
One portrait passenger-awareness poster
One landscape presentation visual
All three designs must use:
The same campaign name
The same colour palette
The same font combination
A consistent visual style
Verified and consistent information
Appropriate disclosure where required
Step 2 — Read the Campaign Brief
Fictional Campaign
Organisation: AeroVista Airports
Campaign Name: Travel Smart at the Airport
Objective: Encourage passengers to arrive prepared and follow verified airport instructions.
Target Audience: Domestic airline passengers
Communication Channels: Social media, terminal poster and presentation
Primary Message: Check official travel information before arriving at the airport.
Supporting Messages:
Check flight status using official airline channels.
Keep travel documents accessible.
Follow official baggage and security instructions.
Monitor airport display screens.
Do not rely on unverified social-media posts.
Restrictions
Students must not:
Use real airline or airport logos.
Invent baggage limits.
Invent security rules.
Include real passenger data.
Promise shorter queues.
Guarantee on-time flights.
Create fake statistics.
use misleading safety signs.
Present an AI-generated scene as a photograph of a real event.
